# test-project

A Node.js web app built with **TypeScript** and **Next.js**.

## Tech stack

- **Runtime:** Node.js
- **Language:** TypeScript
- **Framework:** Next.js (App Router)
- **Config:** dotenv for environment variables

## Getting started

Prerequisites: Node.js and npm.

```bash
npm install
```

Next.js is not scaffolded yet. After it is added, typical scripts will be:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in the browser.
